BOURSEPILOT AI – VERSION 2
==========================

Cette version est conçue comme une page autonome : tout le JavaScript est intégré
dans index.html. Il n'y a donc plus de fichier app.js externe à charger.

PUBLICATION
1. Décompressez le ZIP.
2. Publiez le fichier index.html (ou le dossier qui le contient) sur un hébergeur
   de site statique acceptant les fichiers HTML.
3. Ouvrez l'adresse HTTPS dans Safari sur l'iPhone.
4. Dans Safari : Partager > Sur l'écran d'accueil > Ajouter.

IMPORTANT
- Cette version permet de gérer librement les liquidités, les positions et
  l'historique des opérations.
- Les données sont conservées dans le stockage local du navigateur de l'appareil.
- Les cours sont saisis manuellement.
- Pas de connexion Boursorama, pas de cotations en direct, pas d'ordres boursiers
  et pas de conseil financier.
- Ne supprimez pas les données du site dans Safari si vous souhaitez les conserver.
